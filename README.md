DQC LIVE QUIZ — READY TO UPLOAD

1. This is a browser-only multiplayer quiz. Players need no app or account.
2. Deploy this folder to any Node.js host supporting WebSockets.
3. Run: npm install
4. Run: npm start
5. Host page: /host
6. Click Create Room. Show the generated QR.
7. Players scan the QR and enter their name + room code.

IMPORTANT: The included QR is generated from your deployed public URL. The QR service is only used to render the QR image; participants do not need an account.

Questions are stored in questions.json. The supplied 30 questions, timers and answers are included.
